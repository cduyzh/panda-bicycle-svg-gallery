# 熊猫骑行实验室

本地 SVG 动画画廊。页面按“模型系列 → 具体型号 → 生成配置 → 生成记录”整理作品：每个型号只占一张卡片，在预览面板中切换不同配置与多次生成结果。支持搜索、系列筛选、排序、键盘左右切换和打开原始 SVG。

## 运行方法

```bash
python3 server.py
```

然后在浏览器访问 `http://localhost:8000`。

把新的 SVG 放进本目录即可自动出现在画廊，无须改页面。原文件名会完整保留。比如 `6 Luna Max.svg` 和 `6 Luna Max2.svg` 会归到同一型号、同一配置下；末尾的 `2` 表示再次生成。`0731`、`0813` 这类型号修订编号仍属于型号本身。页面上的日期来自文件修改时间，不代表真实生成时间。
